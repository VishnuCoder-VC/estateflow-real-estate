# 🏡 EstateFlow

A modern, responsive, and elegant **Real Estate Website** built using **HTML, CSS, and JavaScript**. EstateFlow showcases premium properties with a clean user interface, smooth animations, and a mobile-friendly design, making it an ideal front-end portfolio project.
